[center][size=6][b]RandomTweaks[/b][/size][/center]

[center]A handful of quality-of-life tweaks: instant butchering, a wish-list stocking top-up for the Wishing Shelf, hiding the full suit and backpack through transmog, custom teleporter pad names, and configurable player stat adjustments.[/center]

[size=5][b]Requirements[/b][/size]
Built against UE4SS 3.0.1 (commit 1ba38db4) for Abiotic Factor 1.5.0 (Modding Update).

[size=5][b]Installation[/b][/size]
[list=1]
[*]Extract the RandomTweaks zip into [font=courier]../ue4ss/Mods/[/font][/*]
[*]Launch the game[/*]
[/list]

[size=5][b]Configuration[/b][/size]
Edit [font=courier]Mods/RandomTweaks/config.lua[/font].

On the first run the mod writes a default config. Delete [font=courier]config.lua[/font] and restart to regenerate it; it is never overwritten while it exists. Remove a line or set it to [font=courier]nil[/font] to skip that tweak.

[size=5][b]Features[/b][/size]

[size=4][b]Instant Butcher[/b][/size]
Every damage event with a valid damage type gibs the target instantly.

[size=4][b]Wishing Shelf Top-Up[/b][/size]
When the Wishing Shelf spawns gifts, a stocked stocking slot that already holds the same item as the shelf slot is topped up to its max stack instead of being left alone. The amount is rolled from the same quantity range the shelf uses, and items gated behind world flags stay gated.

[size=4][b]Hide Full Suit and Backpack[/b][/size]
The full suit and backpack can be hidden through the Transmog Dresser, the same way as other armor. Config key: [font=courier]transmogHideSuitAndBackpack[/font].

[size=4][b]Nameable Teleporters[/b][/size]
Teleporter pads can be given any name again, as before the fixed tag list. The tag box at the top of the pad's tag menu is editable: type a name (up to 32 characters) and confirm. Pads with the same name link to each other; names ignore upper/lower case. Names are saved with the pad. Config key: [font=courier]nameableTeleporters[/font].

The premade tags are gone from the menu. The list shows the names in use instead, each with the number of pads that have it (e.g. "Main Base (2)"), so an unpaired pad stands out; click one to use it. Pads that still have a tag keep it until renamed.
[list]
[*][b]Multiplayer[/b] - the host (or dedicated server) needs the mod to store and show names. Players without the mod see the pad without a name. On a host without the mod, pads named by a modded player still link by name, but the name is not shown or kept. The name list of the host lists every named pad of the map; other players only see the names of pads near them (the parts of the facility currently loaded for them).[/*]
[*][b]Removing the mod[/b] - on the next load the game converts the names to tags with its own upgrade for old pre-tag names. Check the pads' tags afterwards.[/*]
[/list]

[size=4][b]Player Tweaks[/b][/size]
Adjustable player stats, each independent:
[list]
[*][b]Movement[/b] - walkSpeed, sprintSpeed, ladderClimbSpeed, jumpHeight.[/*]
[*][b]Stamina[/b] - staminaDrainRate, staminaRegainRate.[/*]
[*][b]Comfort[/b] - interactionRange.[/*]
[*][b]Lighting[/b] - lightIntensity, lanternIntensity, disableWatchLight.[/*]
[/list]
